# Git в VS Code vs терминал

## Удобно в VS Code (GUI)
1. Визуальный diff — сразу видно, что добавлено/удалено, не нужно читать `git diff`.
2. Кнопки commit/push/pull — быстро, не нужно помнить команды.
3. Встроенный редактор merge-конфликтов — можно разрешать конфликты кликами.
4. GitLens показывает автора и дату каждой строки (blame) прямо в редакторе.

## Удобнее в терминале (CLI)
1. Сложные операции: rebase -i, cherry-pick, squash, reset --hard — в GUI они спрятаны или неполные.
2. Работа на сервере по SSH — там GUI нет вообще, только терминал.
3. Автоматизация: git-хуки, CI-скрипты, массовые операции — только через CLI.
